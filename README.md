# NagarTrace

The complete independently runnable React/TypeScript project is in `nagartrace-source.zip`. Download and extract it, then follow the included README:

```sh
npm ci
npm run dev
npm run build
npm test
```

Requires Node.js 22.12+. The archive contains all source, supplied photos, the dependency lockfile, and 19 engine tests. Production servers must rewrite client routes to `index.html`.

This is a private development prototype with synthetic roads and companies. No real complaint is sent. No server, authentication, shared database or live authority/contractor integration is connected. The landing page follows the selected Nova Dental design direction without copying its code or assets. Image publication rights remain unverified; keep the repository private.
